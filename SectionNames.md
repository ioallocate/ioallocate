# Section Names

Each section name is a symbol, and the symbol tells you what kind of information is under it.

## Exclamation-mark (!)

Heads-up. This is where I put the status, limits, and warnings. Things you should know before using the project, like what isn't finished, tested, or certified yet.

## Question-mark (?)

What the project is and how it works. This is the explanation section, with the internals, the flow, and the technical details.

## Tilde-mark (~)

Expanding on the project. This covers what you could build on top of it or use it for, not what it does right now.

## Dot (.)

The closing notes. The final statements that wrap things up, like the disclaimers at the end.

## At (@)

Credits. Who helped and how.

## Add (+)

Extras. The tools, dependencies, and tech stack the project uses, plus other things worth mentioning, like tools used during development.

## Plus-Sign (+)

How to extend the project. A step-by-step guide for adding new things to it. The subsections are named after the parts you'd change:

``` all stated ideas are solely used as an example based of my other repositories```

* **Mouse Movement**: adding or changing a movement pattern.
* **Node Pair**: defining the coordinates for a new pattern.
* **Debugger**: pointing the project at a different target.
* **Screenshot**: adding a new class to the vision model.
* **Accuracy**: tuning the thresholds for mouse-movement detection.
* **Confidence**: improving the screenshot detection.
* **Export**: getting the dataset out of Roboflow.
